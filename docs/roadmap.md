# Роадмап

Правила процесса:

- **Никаких тестов и оверинжиниринга.** Ни fake-indexeddb, ни юнит-тестов, ни тяжёлых миграций, ни zod на каждое поле. Проверка — глазами в браузере и в окне Electron.
- **Компактная структура.** База в двух файлах плюс бэкап, репозитории — короткие функции без лишних абстракций.
- **Визуал с первого шага.** После каждого этапа приложение запускается и им можно пользоваться.

## Ловушки, в которые не идём

- Сквозной undo для текста и канваса одновременно.
- Свой редактор с нуля или свой canvas на requestAnimationFrame.
- Сервер, аккаунты, SSR, Redux, TanStack Query — кэшировать нечего.
- Хранение документа в localStorage, HTML-строкой или вместе с base64 картинок.
- Запись в IndexedDB на каждый символ и каждый пиксель перетаскивания.
