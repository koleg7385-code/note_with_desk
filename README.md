## ✨ Ключевые возможности

### 💾 Полная портативность (Offline-First)

* **Изолированное хранилище:** Все пользовательские данные, кеш и IndexedDB сохраняются строго в папку `/data` рядом с исполняемым файлом `.exe`.
* **Чистая система:** Приложение не пишет данные в системный `AppData` и не оставляет мусора в реестре Windows.
* **Безопасное обновление:** Установщик обновляет бинарники, не затрагивая локальные файлы заметок.

### 🎨 Интерактивная доска (Canvas)

* **Свободный холст:** Размещение заметок, стикеров, медиафайлов и текста без ограничений по координатной сетке.
* **Гибкие связи:** Кастомизация соединительных стрелок (толщина, сплошная линия / пунктир, направление, запрет петель на себя).
* **Рисование маркером:** Быстрые зарисовки поверх объектов с поддержкой отмены штрихов через `Ctrl + Z`.
* **Умный фокус:** Текстовые узлы с удобными зонами перетаскивания и автофокусом при создании.

### 📝 Редактор документов

* **Tiptap Engine:** Блочный rich-text редактор с поддержкой заголовков, списков, чек-листов и цитат.
* **Таблицы:** Вставка легковесных таблиц прямо в текст заметки без привязки к сложным внешним схемам.
* **Dark Mode:** Контрастный темный интерфейс без отвлекающих элементов.

### 📊 Базы данных

* **Шаблоны под задачи:** Готовые структуры для трекинга задач и учета финансов.
* **Строгий табличный режим:** Отдельный фокус на структурированных данных без навязанных лишних вкладок.

## 🚀 Быстрый старт

### Предварительные требования

* **Node.js** версии 18.0 или выше
* Пакетный менеджер **npm**

### Клонирование и установка

```bash
# Клонировать репозиторий
git clone https://github.com/username/note_with_desk.git

# Перейти в директорию проекта
cd note_with_desk

# Установить зависимости
npm install

```

### Команды разработки

```bash
# Запуск в режиме разработки (Vite + Electron)
npm run app:dev

# Проверка типов TypeScript
npx tsc --noEmit

# Сборка готового релизного установщика (.exe)
npm run app:build

```

> [!TIP]
> Собранный установщик и распакованная версия без инсталляции (`win-unpacked`) сохраняются в директорию `releases/v0.2.1/`.
